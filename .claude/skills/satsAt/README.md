# SatsAt Skills

Skills for the SatsAt Bitcoin portfolio tracker - "Portfolio tracking for serious Bitcoiners."

## About SatsAt

SatsAt (IronLedger) is a Bitcoin and stablecoin portfolio tracker designed for serious self-custody users with complex wallet setups.

**Core Differentiators:**
- Multisig-native (understands 2-of-3, 3-of-5 wallets)
- UTXO-level cost basis tracking
- Internal transfer detection
- Collaborative custody support (Unchained, Casa)

**Target Users:**
- Mass affluent Bitcoin holders ($100K-$5M)
- High-net-worth individuals with complex setups
- Financial advisors serving Bitcoin clients

**Tech Stack:**
- Next.js 14 (App Router)
- TypeScript
- Supabase (PostgreSQL + Auth)
- Tailwind CSS
- Vercel deployment
